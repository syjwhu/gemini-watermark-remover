# ✦ Gemini 水印去除工具 (Gemini Watermark Remover)

本地、无损去除 Google **Gemini** 生成图片右下角的**白色四角星水印**。基于 **反向 Alpha 混合 (Reverse Alpha Blending)** —— 数学反推还原原始像素，而非 AI 重绘。**图片不上传，纯浏览器处理。**

👉 在线使用 (GitHub Pages)：*部署后填入链接*

## 为什么做这个 / 和现成工具的区别

现成的 Gemini 去水印工具大多**假设水印固定在右下角某个精确位置**。但不同 Gemini 版本、或被裁剪/排版过的图，水印位置会**偏移**——这时固定位置的工具会**找错地方、去不掉**。

本工具的核心区别：**你点一下那颗星，它就吸附到那里精确去除**，因此**不限位置**，能处理那些"现成工具去不掉"的图。

## 用法

1. 打开网页（或本地 `index.html`，需通过本地服务器，见下）。
2. 选择一张或多张 Gemini 图片（支持批量）。
3. **在图上点一下那颗白色四角星的中心** —— 自动吸附并去除。位置不对就再点一次，大小不合适用滑块微调。
4. 点「下载」（导出为 PNG，**自动清除 EXIF / C2PA 元数据**）。

## 原理

Gemini 的可见水印是一张**固定的白色叠加层**：`观测 = (1−α)·原图 + α·255`。
已知每个像素的 α，即可反推：`原图 = (观测 − α·255) / (1−α)`，无损还原。

## 能去 / 不能去

| 水印 | 能否去除 |
|---|---|
| ① 可见白色四角星 | ✅ 能（反向 Alpha 混合，点选定位） |
| ② 导出时的元数据 / C2PA 溯源 | ✅ 能（导出 PNG 自动清除） |
| ③ **SynthID 隐藏像素水印** | ❌ **不能**（遍布全图、设计为抗去除，无法可靠去除） |

## 已知限制（诚实说明）

- α 蒙版是从真实样本反推标定的，对**普通背景上的水印**去除干净；当水印**正好压在文字/细线/多色块叠加**的复杂处时，可能残留**极淡痕迹**，此时可再点一次或手动微调。
- 不同 Gemini 版本水印大小不同（48/96/可调），用滑块适配。
